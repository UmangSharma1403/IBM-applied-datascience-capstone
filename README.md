# IBM Applied Data Science Capstone

This Capstone is the 10th (final) course in the IBM Data Science Professional Certificate specialization. It summarizes all the concepts and skills learned throughout the specialization in the form of a comprehensive project.

## 📄 Project Background

SpaceX is the most successful company of the commercial space age, making space travel more affordable. The company advertises Falcon 9 rocket launches at a cost of **$62 million**, while other providers charge upward of **$165 million** per launch. Much of the cost savings comes from the ability to reuse the first stage of the rocket. Therefore, if we can determine whether the first stage will successfully land, we can estimate the cost of a launch. Using publicly available information and machine learning models, we aim to predict whether SpaceX will successfully reuse the first stage.

## 📄 Questions to Be Answered

* How do variables such as payload mass, launch site, number of flights, and orbit affect the success of the first-stage landing?
* Does the rate of successful landings increase over the years?
* What is the best algorithm for binary classification in this case?

## 📄 Methodology

### 1. Data Collection Methodology

* Using the SpaceX REST API
* Using web scraping from Wikipedia

### 2. Data Wrangling

* Filtering the data
* Dealing with missing values
* Using One-Hot Encoding to prepare the data for binary classification

### 3. Performed Exploratory Data Analysis (EDA)

* Using visualization and SQL

### 4. Performed Interactive Visual Analytics

* Using Folium and Plotly Dash

### 5. Performed Predictive Analysis Using Classification Models

* Building, tuning, and evaluating classification models to ensure the best results
